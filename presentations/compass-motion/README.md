# COMPASS motion presentation

Snapshot of the presentation published at:
https://compass-thinking-nayl-vincent.axmatea.chatgpt.site

This directory is isolated from the main application and its deployment setup.
Serve this directory with any static web server to preview `index.html`.
Keep `motion.css` and `motion.js` next to it.

The presentation includes shortened copy, staggered slide entrances, a replayable
deadline-to-payment correction sequence, and reduced-motion support.

This is a scripted concept, not a connected voice assistant. No microphone or AI
backend is connected. Integrate real voice functionality in the main application;
never put provider credentials in these browser files.

Validation: JavaScript syntax and source parity with the published snapshot.
Browser visual QA remains outstanding. Publishing this directory to GitHub does
not change the application's production deployment.
